<p>任务说明
通过“<a href="/forum/">【任务1】启动过程-Boot from USB</a>”，我们已经可以通过USB将一个二进制文件，上传到板子的SRAM中并执行。基于此，我们可以展开第二个任务：启动到u-boot的命令行。完成该任务的基本步骤包括：</p>
</li>
<li>
<p>通过USB DFU操作，将u-boot SPL image上传到SRAM中并运行[/*]</p>
</li>
<li>
<p>u-boot SPL，初始化板子的SDRAM后，退出[/*]</p>
</li>
<li>
<p>通过USB DFU操作，将u-boot image上传到SDRAM中并运行[/*]</p>
</li>
<li>
<p>u-boot启动后，初始化UART，并执行UART console，进入命令行[/*]</p>
</li>
<li>
<p>涉及的知识点
该任务主要涉及如下知识点：</p>
</li>
<li>
<p>SDRAM的配置和初始化（SDRAM driver）[/*]</p>
</li>
<li>
<p>u-boot driver model[/*]</p>
</li>
<li>
<p>u-boot device tree（和kernel中一模一样，可以统一学习）[/*]</p>
</li>
<li>
<p>u-boot UART driver[/*]</p>
</li>
<li>
<p>u-boot serial console[/*]</p>
</li>
<li>
<p>u-boot command line[/*]</p>
</li>
<li>
<p>完成任务的思路
相比“<a href="/forum/">【任务1】启动过程-Boot from USB</a>”，该任务比较简单，可以拆分为几个独立的部分：</p>
</li>
<li>
<p>SDRAM有关的任务。和具体的版型、SDRAM型号有关，代码量较小。
可以基于具体的板子，完成一篇SDRAM有关的硬件介绍的文章，并给出SDRAM初始化有关的步骤。然后在u-boot SPL的board_init_f函数中配置即可。[/*]</p>
</li>
<li>
<p>u-boot driver model有关的介绍和分析，写一篇文章即可。[/*]</p>
</li>
<li>
<p>u-boot device tree的编写、编译和使用，可以结合博客上的device tree的分析文章，从实战的角度，写一篇文章。[/*]</p>
</li>
<li>
<p>u-boot UART driver的设计和编写，要基于driver model和device tree。
和u-boot的UART框架，以及具体的板子有关，可以出两份文章，一份介绍具体板子UART有关的硬件，一份介绍u-boot的UART框架。文档完成后，直接编写具体板子的代码即可。[/*]</p>
</li>
<li>
<p>u-boot serial console和command line有关的内容，不需要任何的实现，可以写一篇文章，介绍相应的机制，以及使用方式。[/*]</p>
</li>
<li>
<p>u-boot启动流程的第2部分，从u-boot开始，到command line出来，可以写一篇介绍文章。[/*]</p>
</li>
</ol>
<p>最后还是希望大家能捡一些力所能及的任务，和我们一起开发，不然我们全包了的话，太木有意思了（说实话，这些事情对我们来说太小菜一碟了），呵呵~~</p>
<ol>
<li>
<p>任务总结
到目前为止（2016/07/27），该任务在bubblegum 96boards上基本完成，共有如下的文档和代码产出：</p>
</li>
<li>
<p>(/u-boot/boot_flow_2.html)[/*]</p>
</li>
<li>
<p><a href="/x_project/bubblegum_uboot_serial.html">X-004-UBOOT-串口驱动移植(Bubblegum-96平台)</a>[/*]</p>
</li>
<li>
<p><a href="/x_project/bubblegum_uboot_device_tree.html">X-005-UBOOT-device tree移植(Bubblegum-96平台)</a>[/*]</p>
</li>
<li>
<p><a href="/x_project/bubblegum_uboot_pinctrl.html">X-006-UBOOT-pinctrl driver移植(Bubblegum-96平台)</a>[/*]</p>
</li>
<li>
<p><a href="/x_project/bubblegum_uboot_ddr.html">X-007-UBOOT-DDR的初始化(Bubblegum-96平台)</a>[/*]</p>
</li>
<li>
<p><a href="/x_project/bubblegum_uboot_cmdline.html">X-008-UBOOT-支持命令行(Bubblegum-96平台)</a>[/*]</p>
</li>
</ol>
<p>其中“<a href="/x_project/bubblegum_uboot_device_tree.html">X-005-UBOOT-device tree移植(Bubblegum-96平台)</a>”、“<a href="/x_project/bubblegum_uboot_pinctrl.html">X-006-UBOOT-pinctrl driver移植(Bubblegum-96平台)</a>”并不是该任务的必要步骤。而“<a href="/x_project/bubblegum_uboot_ddr.html">X-007-UBOOT-DDR的初始化(Bubblegum-96平台)</a>”，为关键步骤，但受限于资源的缺乏，无法给大家呈现移植过程。</p>
<p>可以通过如下步骤在板子上验证：
1）代码下载（具体可参考“<a href="/x_project/bubblegum_uboot_porting.html">X-003-UBOOT-基于Bubblegum-96平台的u-boot移植说明</a>”）</p>
<pre><code>
[== Undefined ==]
mkidr -p ~/work/xprj
cd ~/work/xprj
git clone https://github.com/wowotechX/build
git clone https://github.com/wowotechX/u-boot
git clone https://github.com/wowotechX/tools

</code></pre>
<p>2）代码编译</p>
<pre><code>
[== Undefined ==]
cd build
make env_prepare    #下载交叉编译工具，只需要执行一次即可
make libusb             #只需要执行一次
make dfu                 #只需要执行一次
make uboot

</code></pre>
<p>3）按住Bubblegum-96的ADFU键，使板子进入DFU模式</p>
<p>4）按住Bubblegum-96的ADFU键不松开，将splboot.bin（就是我们的SPL image）上传到SRAM并执行</p>
<pre><code>
[== Undefined ==]
sudo ../tools/dfu/dfu bubblegum 0xe406b200 ../tools/actions/splboot.bin 1

</code></pre>
<p>5）执行完毕后，会重新进入DFU模式，进入后，可以松开ADFU按键。</p>
<p>6）将u-boot上传到DDR并执行（注意上传位置和CONFIG_SYS_TEXT_BASE 一致）</p>
<pre><code>
[== Undefined ==]
sudo ../tools/dfu/dfu bubblegum 0x11000000 out/u-boot/u-boot-dtb.bin 1

</code></pre>
<p>7）使用串口连接开发板，将可以进入命令行。</p>
