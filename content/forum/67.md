<p>任务说明
通过“<a href="/forum/">【任务3】Linux kernel的配置、编译、加载与启动</a>”，已经可以成功boot linux kernel并点亮LED了。基于此，我们可以展开第四个任务：启动Linux kernel到命令行（验收标准相当直接，不多说了）。完成该任务的基本步骤包括：</p>
</li>
<li>
<p>init/main.c中，增加一个简单的点LED的函数，以便用于最初的debug[/*]</p>
</li>
<li>
<p>为了方便后续的开发，尽早实现kernel的串口打印功能[/*]</p>
</li>
<li>
<p>完善dts文件，增加memory有关的信息，以便kernel可以正确初始化memory[/*]</p>
</li>
<li>
<p>debug IRQ、Timer有关的功能[/*]</p>
</li>
<li>
<p>debug其它功能，使kernel可以正确完成初始化过程[/*]</p>
</li>
<li>
<p>制作一个ramdisk，作为临时的rootfs，并启动至命令行[/*]</p>
</li>
<li>
<p>涉及的知识点
该任务主要涉及如下知识点：</p>
</li>
<li>
<p>Linux kernel early console功能[/*]</p>
</li>
<li>
<p>Linux kernel串口子系统[/*]</p>
</li>
<li>
<p>Linux kernel memory、IRQ、Timer等基础功能的移植[/*]</p>
</li>
<li>
<p>Linux kernel的初始化流程，包括start_kernel、reset_init等[/*]</p>
</li>
<li>
<p>ramdisk、rootfs有关的知识[/*]</p>
</li>
<li>
<p>完成任务的思路
该任务可以拆分为几个独立的部分：</p>
</li>
<li>
<p>将Linux kernel启动流程拆分为较为独立的功能，并完成一系列的分析文档（估计是一个漫长的过程）[/*]</p>
</li>
<li>
<p>为linux kernel early console功能写两篇文章，一篇是功能分析，一篇是移植说明[/*]</p>
</li>
<li>
<p>为linux kernel memory、IRQ、Timer等模块，分别写一篇文章，说明移植过程，并穿插有关的device tree知识[/*]</p>
</li>
<li>
<p>着手进行Linux kernel串口子系统的分析，会产出多篇文章，包括serial、TTY、console等等[/*]</p>
</li>
<li>
<p>写一篇文章，介绍基于ramdisk的rootfs的制作过程[/*]</p>
</li>
<li>
<p>其它等等，欢迎大家补充[/*]</p>

<p>可以通过如下步骤在板子上验证：
1）代码下载（具体可参考“<a href="/x_project/bubblegum_uboot_porting.html">X-003-UBOOT-基于Bubblegum-96平台的u-boot移植说明</a>”）</p>
<pre><code>
[== Undefined ==]
mkidr -p ~/work/xprj
cd ~/work/xprj
git clone https://github.com/wowotechX/build
git clone https://github.com/wowotechX/u-boot
git clone https://github.com/wowotechX/tools
git clone https://github.com/wowotechX/linux
git clone https://github.com/wowotechX/doc    #包含有说明文档

</code></pre>
<p>2）代码编译</p>
<pre><code>
[== Undefined ==]
cd build
make env_prepare   #下载交叉编译工具，只需要执行一次，之前任务有下载过的，请忽略该步骤
make libusb         #只需要执行一次
make dfu             #只需要执行一次
make uboot kernel busybox initramfs uImage

</code></pre>
<p>3）按住Bubblegum-96的ADFU键，使板子进入DFU模式
4）按住Bubblegum-96的ADFU键不松开，将splboot.bin（就是我们的SPL image）下载到SRAM并执行</p>
<pre><code>
[== Undefined ==]
cd ./build
make spl-run    #这是一个快捷命令

</code></pre>
<p>5）执行完毕后，会重新进入DFU模式，进入后，可以松开ADFU按键。
6）连接好串口，将包含Kernel Image、dtb文件以及initramfs的FIT uImage下载DDR并执行</p>
<pre><code>
[== Undefined ==]
cd ./build
make kernel-run    #这是一个快捷命令

</code></pre>
<p>7）执行成功后，可以在串口控制台上看到u-boot、kernel的启动日志，最终会运行到busybox的命令行中。</p>
