<p>adb能用，说明负责poweroff的进程被调度走了。
如果真觉得pm_runtime_barrier的嫌疑比较大，那就查一下这个接口：</p>
<pre><code>
[== Undefined ==]
pm_runtime_barrier--&gt;__pm_runtime_barrier
...
        if (dev-&gt;power.runtime_status == RPM_SUSPENDING                         
            || dev-&gt;power.runtime_status == RPM_RESUMING                        
            || dev-&gt;power.idle_notification) {                                  
                DEFINE_WAIT(wait);                                              

                /* Suspend, wake-up or idle notification in progress. */        
                for (;;) {                                                      
                        prepare_to_wait(&amp;dev-&gt;power.wait_queue, &amp;wait,          
                                        TASK_UNINTERRUPTIBLE);                  
                        if (dev-&gt;power.runtime_status != RPM_SUSPENDING         
                            &amp;&amp; dev-&gt;power.runtime_status != RPM_RESUMING        
                            &amp;&amp; !dev-&gt;power.idle_notification)                   
                                break;                                          
                        spin_unlock_irq(&amp;dev-&gt;power.lock);                      

                        schedule(;                                             

                        spin_lock_irq(&amp;dev-&gt;power.lock);                        
                }                                                               
                finish_wait(&amp;dev-&gt;power.wait_queue, &amp;wait);                     
        } 
...

</code></pre>
<p>首先确认你所使用的系统runtime pm是否使能了（如果没有，就不会是这里）。
如果使能了，有可能在系统poweroff的时候，某个设备正在进入suspend或者resume状态，这时pm_runtime_barrier就会等这个过程结束。如果由于某些原因，无法结束，就导致负责poweroff的进程无法调度回来。</p>
<p>试试在这个里面加一些调试信息。</p>

static ssize_t rtpm_status_show(struct device *dev,
                                struct device_attribute *attr, char *buf)
{               
        const char *p;  

        if (dev-&gt;power.runtime_error) {
                p = &quot;error\n&quot;;
        } else if (dev-&gt;power.disable_depth) {
                p = &quot;unsupported\n&quot;;
        } else {
                switch (dev-&gt;power.runtime_status) {
                case RPM_SUSPENDED:
                        p = &quot;suspended\n&quot;;
                        break;
                case RPM_SUSPENDING:
                        p = &quot;suspending\n&quot;;
                        break;
                case RPM_RESUMING:      
                        p = &quot;resuming\n&quot;;
                        break; 
                case RPM_ACTIVE:
                        p = &quot;active\n&quot;;
                        break;
                default:
                        return -EIO;
                }
        }
        return sprintf(buf, p);
}
