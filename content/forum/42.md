<p>Q: First, source的定义在哪？
A: include/linux/ioport.h
/<em>
 * Resources are tree-like, allowing
 * nesting etc..
 </em>/
struct resource {
    resource_size_t start;
    resource_size_t end;
    const char <em>name;
    unsigned long flags;
    struct resource </em>parent, <em>sibling, </em>child;

/**
 * platform_get_resource - get a resource for a device
 * @dev: platform device
 * @type: resource type
 * @num: resource index
 */
struct resource *platform_get_resource(struct platform_device *dev,
                       unsigned int type, unsigned int num)
{
    int i;

    for (i = 0; i &lt; dev-&gt;num_resources; i++) {
        struct resource *r = &amp;dev-&gt;resource[i];

        if (type == resource_type(r) &amp;&amp; num-- == 0)
            return r;
    }
    return NULL;
}

<p>dtsi并不对dts补充，相反，dts会覆盖dtsi中的相同内容。
你这种情况，noway~
另外，你这个需求，本身也是不合理的。应该遵循这样的原则：
dtsi抽象共性，dts抽象差异，因此要改也是改dts。</p>
