<p>我现在是有一份git管理的项目代码，其中有若干分支，现在想要把其中一个分支clone一份到本地路径。但是clone时会报如下错误：
fatal: attempt to fetch/clone from a shallow repository
fatal: The remote end hung up unexpectedly
网上搜了好多，都和我的现象不符合，现在不知道该怎么clone了，特来向各位请教一下。</p>
<p>其中原 git管理的项目代码，是网盘上下载的打包文件，然后 解压后执行命令 “git checkout” 获得，在此基础上又自己创建了一些新的分支。</p>
</div>

<div class="post">
<p class="meta"><strong>wowo</strong> · 2017-02-28 15:57</p>
<p>试试--depth选项，例如：
git clone --depth 1 xxx</p>

<div class="post">
<p class="meta"><strong>三少</strong> · 2017-03-01 20:01</p>
<p>-depth选项很有用。另外一个比较有用的选项是 --single-branch。
我这里的问题，还有一个影响因素就是git的版本，Ubuntu12.04默认的版本是1.7几的，对shallow repository有一些限制。需要升级一下git版本。网上找到的一个升级方法如下：支持Ubuntu 12.04、14.04、14.10、15.04 及其衍生版本。
sudo add-apt-repository ppa:git-core/ppa
sudo apt-get update
sudo apt-get install git</p>
