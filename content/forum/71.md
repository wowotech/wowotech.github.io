<p>这次的版本号是0.609。</p>
<p>主要增加了mm_struct, vm_area这两个数据结构。这是一个大的进步。
新添的几个功能是：mmap(, brk(, fork(, execve(。
fork(和execve(我感觉我一直在写，原先内核那么简陋的时候，就有一个裸奔的fork(和execve 。。。</p>
<p>内核线程只能fork(出来内核线程。内核线程可以（也只可以）execve(出来用户进程。
用户进程fork(和execve(出来的当然都是用户进程。
上面4步都走完，fork(和execve(的功能基本就具备了。我编写的顺序也是这样。现在完成了第三步。</p>
<p>这是papaya内核的第一个用户程序：</p>
<pre><code>
[== Undefined ==]
#include &quot;syscall.h&quot;

static char g_array[10] = {1, 2, 3, 4, 5, 6};
int static_array[1024];
void doado(void){
    int x;
    for(int i = 0; i &lt; 10; i++) printf(&quot;%u\n&quot;, g_array[i]);   //测试.data的内存区
    int ret = fork(;
    printf(&quot;I am back ! %u\n&quot;, ret);
    while(2){
        static_array[1023] = 3;   //这一句是测试bss的内存区
    }
}

</code></pre>
<p>它是这么编译的：</p>
<pre><code>
[== Undefined ==]
doado: doado.c
    gcc -c doado.c -fno-builtin -std=c99 -g
    ld -static -e doado -o doado doado.o

</code></pre>

<img alt="" src="http://images2015.cnblogs.com/blog/491175/201609/491175-20160924012039215-454944723.png" /></p>
<p>上面的12345, 123是fork(后，父子进程各自收到的返回值。
那些页错误，有的是copy-on-write，有的是map on demand。</p>
