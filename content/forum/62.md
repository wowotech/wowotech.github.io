<p>当前由于工作需要，在程序中需要测试每个xxx_init驱动接口函数的初始化时间：</p>
<p><strong>Step1</strong></p>
<pre><code>往往这个时候，想到的是printf 的__TIME__(在源文件中插入当前编译时间)，

然而，大家都知道，printf的话，会严重影响时间的准确性。
</code></pre>
<p><strong>Step2</strong></p>
<pre><code>这个时候想到，如果在xxx_init之间插入printf打印时间有影响的话，那就把xxx_init的每个时间点记录在数组中，在初始化完成之后，统一将时间打印出来：
</code></pre>
<p>然后有了下面的做法：</p>
<p>以下是一个程序中的打点函数：</p>
<h1>define DOT_SIZE 300</h1>
<p>typedef struct{    //</p>
<pre><code>unsigned int cnt;

unsigned int recor;
</code></pre>
<p>}Dot_rec;</p>
<p>Dot_rec dotrec = {0,{0}};</p>
<p>void trace(unsigned int line,unsigned int rec)</p>
<p>{   </p>
<pre><code>dotrec.recor = line;

dotrec.cnt++;

if(DOT_SIZE == dotrec.cnt)

{

    dotrec.cnt = 0;

}

dotrec.recor = rec;

dotrec.cnt++;

if(DOT_SIZE == dotrec.cnt)

{

    dotrec.cnt = 0;

}
</code></pre>
<p>}</p>
<h1>define ltrace(a) trace(<strong>LINE</strong>,(unsigned int)(a));</h1>
<p>void printrace(void)</p>
<p>{   </p>
<pre><code>int num;

DRV_Printf("cnt = %d\n",dotrec.cnt);

for(num= 0; num &amp;lt; DOT_SIZE; num++)

{

    DRV_Printf("%d,",dotrec.recor[num]);

    num++;

    DRV_Printf("%x,",dotrec.recor[num]);

    if(num%20 == 19)

    {

        DRV_Printf("-%d\n",num);

    }

}

DRV_Printf("\n");
</code></pre>
<p>}</p>
<p>这个Step2，实际只是想想，并未采用该方法。</p>
<p><strong>Step3</strong></p>
<pre><code> 如果是用printf的__TIME__，打印的时间精确到秒级，测量程序执行时间，显然是不够用的。

 因此想到，使用clock_gettime(CLOCK_MONOTONIC, &amp;amp;ts);
</code></pre>
<p>可以获得足够精确的每个xxx_init程序代码执行时间。</p>
<pre><code>代码如下：
</code></pre>
<h1>include &lt;time.h&gt;</h1>
<h1>define DOT_SIZE 600</h1>
<p>typedef struct{    //</p>
<pre><code>unsigned int cnt;

unsigned long recor;
</code></pre>
<p>}Dot_rec;</p>
<p>Dot_rec dotrec = {0,{0}};</p>
<p>void trace(unsigned int line,time_t tv_sec,long tv_nsec)</p>
<p>{   </p>
<pre><code>dotrec.recor = line;

dotrec.cnt++;

if(DOT_SIZE == dotrec.cnt)

{

    dotrec.cnt = 0;

}

dotrec.recor = tv_sec;

dotrec.cnt++;

if(DOT_SIZE == dotrec.cnt)

{

    dotrec.cnt = 0;

}

dotrec.recor = tv_nsec;

dotrec.cnt++;

if(DOT_SIZE == dotrec.cnt)

{

    dotrec.cnt = 0;

}
</code></pre>
<p>}</p>
<h1>define ltrace(a,b)  trace(<strong>LINE</strong>,(time_t)a,( long b);</h1>
<p>void printrace(void)</p>
<p>{   </p>
<pre><code>int num;

printf("cnt = %d\n",dotrec.cnt);

for(num = 0; num &amp;lt; DOT_SIZE; num++)

{

    printf("%d,",dotrec.recor[num]);

    num++;

    printf("%x,",dotrec.recor[num]);

    num++;

    printf("%x,",dotrec.recor[num]);

    if(num%20 == 19)

    {

        printf("-%d\n",num);

    }

}

printf("\n");
</code></pre>
<p>}</p>
<p>这样的话，就满足了测试实际程序执行时间的要求.</p>

<p>以前debug启动时间的时候，是这样做的：
在bootloader启动的瞬间，启动一个专门用于启动时间优化的硬件timer。
然后在需要确认时间的点上，将timer的当前值保存在固定的memory区域，然后在需要的时候，打印出来。
这样的好处是，可以精确知道从boot、到kernel、再到Application，各个阶段的精确时间。</p>
